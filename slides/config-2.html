Mitar's Tactic Configuration
# 带参数捕获：unfold.toml name = "unfold" syntax = "unfold $concept" # $concept 捕获标识符 tag = "应用定义" content = "根据 ${concept} 的定义, 我们需要证明 ${goal'}" # 条件分支：have.toml name = "have" syntax = "have" tag = "引入前提" put_off = true # 产生新自由变量的策略 content = "要证明该命题, 只需证明 ${goal}" [Final] # 终结步骤时覆盖 content content = "由此可得 ${goal}" [Contra] # 目标为"矛盾"时覆盖 content content = "推出矛盾，因此原命题得证" # 加载到项目中 #load_tactics mathlib -- 加载 Mathlib 内置策略规则 #load_tactics_toml ".../my_tactics/" -- 加载自定义策略规则目录

一条 TOML，一种策略

每个策略一个 .toml 文件。54 种策略已适配（内置 28 + Mathlib 26），新增策略只需新建一个文件。

语法匹配

syntax 字段用 $label 捕获参数，前缀优先匹配。$goal 和 $goal' 捕获策略前后的证明目标。

内容模板

content 中用 ${label} 引用捕获的参数，${goal} 引用当前目标。文本一经写出，Mitar 自动渲染为 KaTeX 数学公式。

条件分支

Final（终结步骤）、Contra（导出矛盾）、NonFinal（未完成）——同一策略在不同上下文中展示不同内容。

拖后记录

put_off = true 处理 have 等产生新变量的策略，确保新变量在后续步骤中才被记录。

开箱即用

内置 54 种策略规则，覆盖日常证明需求。mitar make file.lean 一键生成交互式 HTML。
