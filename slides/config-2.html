Mitar's Tactic Configuration
# unfold.toml (带参数捕获) name = "unfold" syntax = "unfold $concept" # `$concept` 捕获参数 tag = "应用定义" content = "根据 ${concept} 的定义, 我们需要证明 ${goal'}" # norm_num.toml (条件分支) name = "norm_num" syntax = "norm_num" tag = "数值" put_off = true content = "该命题在数值上可标准化为 ${goal}" [Final] # 作为终结步骤时覆盖原有模版 content = "通过数值计算即可证明 ${goal}" [Contra] # 目标为“矛盾”时覆盖原有模版 content = "在数值上不相等, 由此产生矛盾" # 加载到项目中 #load_tactics mathlib # 加载 Mathlib 内置策略规则 #load_tactics_toml ".../my_tactics/" # 加载自定义策略规则目录

一条 TOML —— 一种策略

每个策略用法对应一个 .toml 文件, 内置 54 种策略 . ( Lean 28 + Mathlib 26 )

智能语法匹配

syntax 字段用 $label 捕获参数, 前缀优先匹配.
使用 $goal 和 $goal' 可捕获策略前后的证明目标.

条件分支

Final (终结步骤)、Contra (导出矛盾)、NonFinal (中间步骤)
同一策略在不同上下文中展示不同内容.

延迟记录

put_off 处理 have 等产生新变量的策略, 确保新变量在产生后才被记录.

Mathlib 版本隔离

Mathlib 策略规则作为配置文件, 确保在不同 Mathlib 版本下都能正确工作.
