未定相等 =?

处理部分函数的天然方案

极限计算中表达式可能无定义。A =? B 含义：若 B 无定义则成立，否则 A = some B。允许 calc 跳过未定义项，贴合手算习惯。

自反 + 传递 + 混合

=? 可与 = 无缝混合于 calc 块。证明流的可读性与数学草稿一致。

-- =? 的定义：B 无定义时无条件成立 def UdEqual (A B : Option α) : Prop := match B with | none => True | some B! => A = the B! infix:50 " =? " => UdEqual

表达式系统

统一的 Function 抽象

数列、函数、表达式统一到 Function，domain（定义域）和 map（映射）是核心字段。定义域是值而非命题，贴合直觉。

Option 承载部分性

函数值类型为 Option ℝ，none 表未定义。the 宏是 Option.some 语法糖。与 =? 协同处理边界。

-- 数列极限：SeqLimit(A, L) 即 A 收敛于 L def SeqLimit (A : Sequence) (L : ℝ) : Prop := A.final = none ∧ ∀ ε > 0, ∃ N : ℕ, ∀ n > N, A.map n ∈ Nbho L ε -- 函数极限：四种方向统一接口 def FuncLimit | LeftLimit def RightLimit | NegInftyLimit
