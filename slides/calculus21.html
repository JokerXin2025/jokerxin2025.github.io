表述 & 计算分层设计

表述层

带有定义域的 Function 类型

使用带有 Lean 原生函数和定义域集合的结构体作为函数和数列的定义, 将定义域提升为 一等公民 , 贴合直觉的同时允许关于定义域的命题表述

@[ext] structure Function where map : ℝ → ℝ domain : Set ℝ
计算层

伴随未定相等 =? 使用的 Option 表达式

并行开发专用于计算的表达式系统, 使用 Option 类型表示运算结果, 配合未定相等的引入使得如手写般的形式化证明成为可能

-- =? 的定义: B 无定义时无条件成立 def UdEqual (A B : Option α) : Prop := match B with | none => True | some B! => A = the B! infix:50 " =? " => UdEqual

定制策略

lim_calc 连续性代入

基于初等函数的连续性直接代入极限点计算

lim_congr 极限表达式改写

利用去心邻域内同余性对极限表达式进行改写，支持嵌入 ring / field 等自动化终结策略

lim_equiv 等价无穷小代换

自动匹配 $\sin x\sim x$ 等常见等价无穷小

lim_rational 有理函数极限计算器

与 SymPy 交互，自动因式分解并求解有理函数极限

deriv 导数计算器

计算初等函数的导数值

lim_luo 应用洛必达法则

使用洛必达法则, 对 $0/0$ 或 $\infty/\infty$ 型不定式同时求导分子和分母

int_notice 积分验证器

直接通过求导验证不定积分/定积分结果

int_by_parts 应用分部积分法

使用分部积分法, 对不定积分/定积分进行拆分
